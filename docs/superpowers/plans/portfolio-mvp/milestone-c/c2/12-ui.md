### Task 5: "Ask about this problem"

**Files:** Modify `src/mathtutor/web/templates/practice.html`,
`src/mathtutor/web/static/practice.js`, `src/mathtutor/web/static/app.css`,
`tools/e2e/smoke.mjs`. Test: `tools/web/help_panel.test.mjs`.

**Interfaces:** consumes `item.help.types` containing `"question"` (Task 3) and
`POST /api/help` with `question` (Task 4). Copy is decision Q7; use it verbatim.

Placement (Q7): directly under the answer box, both visible at the same time; inside
`#help-controls` after the explain row:

```html
<span id="help-question-row" class="help-question-row" hidden>
  <label for="help-question">Ask about this problem</label>
  <textarea id="help-question" maxlength="500" rows="2"
    placeholder="For example: why does the chain rule apply here?"></textarea>
  <span id="help-question-count" class="hint" aria-live="polite">0/500</span>
  <button type="button" id="help-ask">Ask</button>
</span>
```

Behavior:
- Shown when `types.includes('question')`; hidden with the rest when help is off.
- Counter counts code points (`[...value].length`), like the server. `Ask` is disabled when
  the trimmed text is empty or over 500. `help-ask` and `help-question` join `HELP_IDS`.
- Retry (C1-R8): `helpKey(type, confusion, question)` adds the trimmed question text to the
  existing `helpUnresolved` key, and the kept body carries the question. A retry of the same
  text after a lost response reuses the request id; edited text is a new request.
- `askHelp('question')` sends `question: value` (raw; the server normalizes). On
  `delivered`/`fallback`/`abstained` the textarea keeps its text (the student may rephrase);
  `clearHelp()` (new item, correct, reveal) empties it and resets the counter.
- A 400 `invalid_question` shows the server's `message` in `#help-message`.
- Ctrl/Cmd+Enter in the textarea triggers Ask; plain Enter inserts a newline.
- Disclosure text (Q7): "When you ask for help, your problem, your recent answers and any
  question you type are sent to Anthropic's Claude to write the reply. …" (rest unchanged);
  Task 9 appends the Q9 ratings sentence.
