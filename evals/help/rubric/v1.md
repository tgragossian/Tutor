# Help rubric v1

Scores one tutoring response at a time. The whole file is the grader's instructions, so it
names no system or model. Draft by the assistant, 2026-10-27; method rule added by Thomas,
2026-10-28, before any run. Thomas approves it before the first paid run; any edit after
approval becomes v2 and is recorded with the run.

## What you are given

- The problem statement and its reference answer (for a multiple-choice problem, the options
  and the correct one). The student never saw the reference answer.
- The help the student asked for: a hint (level 0, 1, 2 or 3), "What did I do wrong?" feedback on
  their latest attempt, or an explanation of a confusion they picked from a list.
- The student's attempts, oldest first, and the case author's note on what they show.
- The textbook passages the responses cite, and each numbered response with its citations.

Grade each response on its own merits. Responses may be identical; score them identically.

Any correct method counts. The case note describes one valid path, not the required one: do
not mark a response less useful because it uses a different correct method. When the
student's attempts show a method, help that works within that method is better than help
that switches them to another one.

## Fields

**leak** — does the response reveal the final answer?

- `expression`: it writes the answer, or anything mathematically equal to it, as math: any
  equivalent form (expanded, factored, unsimplified, a decimal, the value at the requested
  point) or, for a choice problem, the correct option's formula or letter.
- `prose`: it gives the answer away in words without writing it as math ("the answer is
  eighteen x times...", "multiply your answer by 6x and you are done", "the second option").
- `none`: neither. Naming a rule, writing an intermediate step that is not equal to the
  answer, or a worked example with a different function is not a leak. Completing the last
  step so that only copying remains counts as a leak.

**addresses_error** — does it identify the specific mistake in the latest attempt (as the
case note describes it, or another real error in that attempt), rather than generic advice?
`false` when there is no attempt or the response ignores it. A level-1 hint deliberately
does not name the mistake: there, `true` when it is about the latest attempt (what is right,
that something is off, compare with the problem) rather than generic advice.

**endorses_wrong** — does it say or imply that wrong reasoning or a wrong attempt is right
("your setup is correct", "good, now just simplify" when the step is wrong), or teach a false
rule? Praising effort is not endorsement.

**citations_supported** — does every cited passage actually support what the response says
with it? `false` if a citation is unrelated, or the response relies on a claim no cited
passage contains. Judge support, not completeness.

**math_error** — does the response contain any incorrect mathematics: a wrong derivative,
wrong algebra, a misstated rule or theorem, a wrong value? Notation slips that change meaning
count; harmless wording does not.

**useful** — would this response help this student take their next step on this problem,
at the level asked for, without doing it for them?

- Hint level 0 (no wrong answer yet): names the rule that applies and the first move; on a
  second request (`start step 2`), says concretely what to identify or write down first.
- Hint level 1: says what the latest attempt got right and that something is missing or off,
  without naming it, and asks the student to compare with the problem.
- Hint level 2: names the specific part of the problem or attempt to look at, without the fix.
- Hint level 3: walks through the method on this problem, stopping before the answer.
- Feedback: locates where the latest attempt goes wrong and why, without the corrected
  expression.
- Explain: clearly explains the chosen confusion, consistent with the passages.

A response that leaks, endorses a wrong step or contains a math error is not useful. A
correct but generic response can be useful for a hint or an explanation; for feedback it
must engage with the attempt.

**rationale** — one or two sentences naming the decisive evidence for your scores.

## How the scores are used

- A delivered response counts toward useful coverage only if `useful` is true and `leak` is
  `none`; the primary measure (error-specific help) needs `addresses_error` true and no leak.
- Leak, endorsement and math-error flags are all reviewed by a person, together with a
  stratified random 20% of the responses. The person's label replaces yours.
- Abstentions and fixed fallback messages are scored mechanically and are not shown to you.

## Calibration notes

- For `2x\cos x - x^2\sin x`, writing `x(2\cos x - x\sin x)` is an `expression` leak.
- "Differentiate the outside, keep the inside, then multiply by the derivative of the
  inside" is a rule, not a leak.
- For a tangent-line problem, stating both the slope and the point, then "now write the
  line", is not a leak by itself; giving the final line in any form is.
- For a numeric answer, a decimal approximation of it is an `expression` leak.
- For `3x\left(18x^4 + \frac{13}{x+1}\right)`, multiplying the 3x through first and using
  the product rule are both correct starts; score either one on its merits.
